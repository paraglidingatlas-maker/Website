# Figures for the Kenya option page

Noto Emoji drawings (Google, Apache License 2.0, LICENSE here), from the noto-emoji repository at tag v2.042, one file per
figure: elephant 1f418, giraffe 1f992, zebra 1f993, rhino 1f98f, hippo 1f99b, buffalo 1f403, lion 1f981, flamingo 1f9a9,
runner 1f3c3, cattle 1f402 (ox), walker 1f6b6, crocodile 1f40a. baobab.svg is drawn here in the same manner, since no emoji
has one. tools/v4_kenya_e.py inlines them as SVG symbols in the page; prototypes/v4/fly.js moves them on the ground.
